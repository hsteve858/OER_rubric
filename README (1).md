# IMAGO OER Evaluation Rubric

A rubric for evaluating the open educational resources (OER) curated for IMAGO. It rates each resource on nine criteria so curators can compare resources consistently and record why a resource was or was not included.

The full rubric is in [IMAGO_OER_Evaluation_Rubric.md](IMAGO_OER_Evaluation_Rubric.md).

## What it covers

| Rubric | What it rates | Scale |
| --- | --- | --- |
| I. Alignment to standards | How fully the resource addresses a standard's content and performance expectations | 0-3 or N/A |
| II. Explanation of the subject matter | How well the resource explains content to learners | 0-3 or N/A |
| III. Utility of teaching-support materials | How usable the resource is for teachers planning or presenting | 0-3 or N/A |
| IV. Quality of assessment | Whether assessment items match and fairly measure the intended learning | 0-3 or N/A |
| V. Technological interactivity | Whether interactive features respond to the learner and serve learning | 0-3 or N/A |
| VI. Instructional and practice exercises | Quantity, clarity and variety of practice, with answer keys | 0-3 or N/A |
| VII. Opportunities for deeper learning | Whether learners use skills such as critical thinking, collaboration and modeling | 0-3 or N/A |
| VIII. Accessibility | Yes/no checklist of accessibility characteristics | Yes / No / N/A |
| IX. Open licensing and reuse rights | Whether the license lets users retain, reuse, revise, remix and redistribute | 0-3 or N/A |

Scores: 3 Superior, 2 Strong, 1 Limited, 0 Very weak, N/A Not applicable.

## How to use it

1. Copy the resource information form and score summary table from the rubric for each resource you review.
2. Review the smallest meaningful unit of the resource, such as one lesson or video.
3. Score each rubric on its own, using N/A where a rubric does not fit.
4. Complete the Rubric VIII checklist if you are qualified to judge accessibility.
5. Use the decision guide at the end of the rubric to decide whether to include the resource.

## Items to fill in before first use

- Rubric I: IMAGO's standards or outcomes.
- Rubric VIII: the WCAG conformance level (A or AA).
- Rubric IX: which license types IMAGO accepts.
- Decision guide: the suggested score thresholds are a starting point and can be changed.
